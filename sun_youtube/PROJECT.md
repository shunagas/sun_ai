# YouTube部門 プロジェクトファイル（@sun-viaje）

> このファイルはリーダーAgent「[[sun_youtube]]」が管理する。
> 詳細な一覧データはCSVを参照（読み込み過多を避けるため、全件は grep/検索で引く）。
> 全体方針は [../PROJECT.md](../PROJECT.md) を参照。

## データファイル
| ファイル | 内容 |
|---|---|
| [data/videos.csv](data/videos.csv) | 長尺・ショート動画の公開履歴 ＋ 今後の投稿予定（date, type, status, title） |
| [materials/progress-log.md](materials/progress-log.md) | 毎晩の定例会議（進捗分析＋次アクション討議）のログ。2026-09-08〜運用 |
| [../sun_develop/materials/youtube_video_daily.json](../sun_develop/materials/youtube_video_daily.json) | 直近30日・動画別（上位10本）の日次再生数/視聴時間。YouTube Analytics API/Data API由来、本人がローカルで定期取得しpushする一次情報源 |

実績KPI数値（視聴回数・登録者数・インプレッション等）はYouTube Studioアナリティクスが一次情報源。定期的にダッシュボードを直接確認して分析すること（`data/kpi_monthly.csv.enc`による暗号化管理は2026/9に廃止済み）。

検索例:
```
# 未消化の投稿予定だけ見る
awk -F, '$3=="planned"' sun_youtube/data/videos.csv
# 特定の月の予定を見る
grep 2026-10 sun_youtube/data/videos.csv
```
