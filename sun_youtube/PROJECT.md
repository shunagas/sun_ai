## データファイル
| ファイル | 内容 |
|---|---|

実績KPI数値（視聴回数・登録者数・インプレッション等）はYouTube Studioアナリティクスが一次情報源。定期的にダッシュボードを直接確認して分析すること（`data/kpi_monthly.csv.enc`による暗号化管理は2026/9に廃止済み）。

検索例:
```
# 未消化の投稿予定だけ見る
awk -F, '$3=="planned"' sun_youtube/data/videos.csv
# 特定の月の予定を見る
grep 2026-10 sun_youtube/data/videos.csv
```

## 制作方針・制約
- 動画内で顔出しはしない。企画・サムネ・撮影方法の検討時はこの前提を踏まえること。

## 目標（2026年末）
> 2026.9.2の全社目標見直し後、本人がA/B目標として再確定（すん旅事業.xlsxが一次情報源）。2026-09-10、チーム検討を経て本人が最終判断。
- 長尺動画30本（A/B共通、参考目標）
- チャンネル登録者：A目標500人／B目標300人
- 視聴時間：A目標4,000時間／B目標2,400時間
- 長尺再生数：A目標50,000回／B目標30,000回
- **2026年末はB目標（登録者300人・視聴時間2,400時間・視聴回数30,000回）の3項目全て達成を必達とする**（2026-09-10本人確定。長尺動画数30本はこの必達条件には含まない）。現状の実績トレンドに基づく簡易試算では、この3項目全達成の確率は約43%（登録者60%×視聴時間80%×視聴回数90%、各項目独立仮定の概算）。
