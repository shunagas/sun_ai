## データファイル
| ファイル | 内容 |
|---|---|
| [data/kpi_monthly.csv](data/kpi_monthly.csv) | 月次KPI実績（2026年5月〜8月）と9月目標 |
| [data/videos.csv](data/videos.csv) | 長尺・ショート動画の公開履歴 ＋ 今後の投稿予定（date, type, status, title） |

検索例:
```
# 直近の実績を見る
tail -1 sun_youtube/data/kpi_monthly.csv
# 未消化の投稿予定だけ見る
awk -F, '$3=="planned"' sun_youtube/data/videos.csv
# 特定の月の予定を見る
grep 2026-10 sun_youtube/data/videos.csv
```

## 直近スナップショット
実際のKPI数値（視聴回数・登録者数など）は非公開情報のため、このリポジトリでは`data/kpi_monthly.csv.enc`として暗号化して管理している。復号にはパスフレーズが必要（ユーザー本人とnightly routineのみ保有）。

数値の更新は、ローカルの平文ファイルを編集後、暗号化して`.enc`を上書きする。
