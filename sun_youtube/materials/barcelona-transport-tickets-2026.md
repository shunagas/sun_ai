# バルセロナ公共交通チケット比較（2026年・ゾーン1）

YouTube用の図解素材。料金は2026年1月15日改定のTMB公式料金（2026-09-23時点で確認）。購入前に公式で要再確認。

- 空港メトロの片道は「空港チケット」€5.90（往復€11.80）

## 損益分岐点

| 比較 | 計算 | この回数からお得 |
|---|---|---|
| T-casual vs シングル | €13.00 ÷ €2.90 = 4.5 | **5回以上** |
| T-familiar vs シングル | €11.50 ÷ €2.90 = 3.97 | **4回以上**（2人で合計4回でもOK） |
| Hola 24h vs T-casual（空港メトロ使わない日） | €12.50 ÷ €1.30 = 9.6 | 1日**10回以上**（現実的にほぼ無い） |
| T-usual vs T-casual | €22.80 ÷ €1.30 = 17.5 | 30日で18回以上（長期滞在向け） |
| Hola 48h vs 空港往復+T-casual | (€18.70−€11.80) ÷ €1.30 = 5.3 | 市内**6回以上** |
| Hola 72h vs 空港往復+T-casual | (€27.30−€11.80) ÷ €1.30 = 11.9 | 市内**12回以上** |
| Hola 96h vs 空港往復+T-casual | (€35.60−€11.80) ÷ €1.30 = 18.3 | 市内**19回以上** |
| Hola 120h vs 空港往復+T-casual | (€43.60−€11.80) ÷ €1.30 = 24.5 | 市内**25回以上** |

※Holaの分岐は「空港メトロを往復とも有効時間内に使う」前提。空港メトロを使わない場合、Holaは1日7回以上乗らないと元が取れない。

## 結論（動画の締め）

1. **迷ったらT-casual**：5回乗ればシングルより得、1回€1.30
2. **夫婦・友人で少しだけ乗るならT-familiar**：2人でシェア可、合計4回で元が取れる
3. **Hola BCNは空港メトロ往復を使い、1日3〜4回以上乗る人向け**
4. Hola 24hは1日10回以上乗らないとT-casualに負ける（1日観光ならT-casualで十分）
